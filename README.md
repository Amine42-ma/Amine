# 👑 بطل رويال — Royal Builder

محرّك ألعاب صغير يعمل داخل المتصفح، تبني به لعبة **باتل رويال ثلاثية الأبعاد** خطوة بخطوة،
ثم تُصدّرها **كملف HTML واحد** يعمل بلا إنترنت.

كل شيء بالعربية، من اليمين لليسار، ويعمل باللمس على الجوال وبالفأرة/لوحة المفاتيح على الحاسوب.

---

## التشغيل

```bash
npm install
npm run build      # يبني ملف index.html الواحد
npm start          # خادم محلي على http://127.0.0.1:8099
```

ثم افتح `http://127.0.0.1:8099/index.html`.

> **مهم:** المحرّر يجلب نماذج GLB من مجلد `assets/`، لذلك يحتاج خادماً محلياً (لا يعمل بفتح الملف
> مباشرة من القرص). أمّا **اللعبة المُصدَّرة** فهي ملف واحد مكتفٍ بذاته يُفتح مباشرة بنقرة مزدوجة.

## المراحل الأربع

### 1️⃣ أزرار التحكم
ترتيب واجهة اللعب **قبل** بدء اللعب:

- الأزرار: التحرك (عصا)، التصويب (عصا)، الضرب، القفز، الجري، الانخفاض، **فتح الصناديق**،
  **التقاط الأشياء**، إعادة التعبئة، التعبير.
- اسحب أي زر لتغيير مكانه، واسحب المقبض الأصفر لتغيير حجمه.
- **ارفع صورة** لتكون أيقونة الزر (PNG شفاف أفضل)، أو اختر رمزاً جاهزاً.
- تحكّم في الشفافية والشكل (دائري/مربع) والإظهار/الإخفاء.
- **واجهة المعلومات**: عدّاد القتلى 💀، الترتيب 🏆، عدد الباقين 👥، شريط الصحة ❤️،
  والخريطة المصغّرة 🗺️ — كلها قابلة للتحريك وتغيير الحجم.

### 2️⃣ الخريطة والمسارات
- تُحمَّل خريطة GLB وتُحلَّل تلقائياً (تفاصيل التحليل بالأسفل).
- **الخريطة ثنائية الأبعاد** تملأ الشاشة: اسحب للتحريك، عجلة الفأرة للتكبير، زر «⤢ ملاءمة» للعودة.
- **✈️ رسم مسارات الطيران**: اضغط نقطة بعد نقطة لرسم الخط، «↶ نقطة» للتراجع عن آخر نقطة،
  «✓ إنهاء» للحفظ. تستطيع إنشاء عدة مسارات وحذف أيّها.
  عند بدء المباراة يُختار **خط عشوائي**، وقد تبدأ الطائرة **من بدايته أو من نهايته** عشوائياً.
- **📦 الصناديق**: توزيع تلقائي احترافي، أو إضافة/تحريك/حذف يدوي بالسحب.
- **🚧 الحدود**: توليد تلقائي لشكل الجزيرة (يمنع الوصول إلى البحر)، أو **رسم يدوي** نقطة بنقطة،
  مع إمكانية تحريك أي نقطة لاحقاً وشريط «تقليص الحدود عن الشاطئ».
- **🧊 عرض ثلاثي الأبعاد** لتفقّد الخريطة والصناديق والمسارات والجدار داخل المشهد.
- إعدادات: ارتفاع وسرعة الطائرة، عدد الخصوم ومهارتهم، وقت النهار.

### 3️⃣ القائمة الرئيسية
قائمة بأسلوب براول ستارز، كلها قابلة للترتيب:

- اسحب أي زر لتغيير مكانه/حجمه: اللعب، المتجر، الأبطال، المهام، الأزياء، الأخبار،
  الأصدقاء، الاتحاد، الإعدادات — أو أضف **أزراراً مخصّصة**.
- لكل زر: النص، اللون، الشارة الصغيرة، **الأيقونة (صورة مرفوعة)** أو رمز جاهز، والوظيفة عند الضغط.
- **الخلفية**: ارفع صورتك أو اختر تدرّجاً لونياً.
- **👥 الأصدقاء**: أضف أصدقاء بالاسم، ويظهرون مقسّمين إلى **«متصلون الآن»** و**«غير متوفّرين»**،
  مع إمكانية الحذف وتبديل الحالة.
- **🛒 المتجر**: أضف/احذف عناصر بأسمائها وأسعارها وأيقوناتها.
- **🧍 الشخصية**: كبسولة بعينين — لوّن الجسم والبطن والعينين والحد الخارجي، وغيّر الطول والعرض
  وحجم العينين، و**أضف نماذج GLB** (نظارات، قبعة، سلاح…) وثبّتها على الوجه/الرأس/الجسم/اليد/الظهر
  مع تحكّم كامل في الحجم والإزاحة والدوران.

### 4️⃣ التصدير
- **▶️ تجربة اللعبة الآن** داخل المحرّر مباشرة.
- **⬇️ تنزيل ملف HTML واحد** يحوي المحرّك + الخريطة + الطائرة + الصناديق + الأيقونات + الإعدادات.
- تصدير/استيراد الإعدادات كملف JSON.

## اللعب

| الفعل | لوحة المفاتيح | اللمس |
|---|---|---|
| التحرك | `W A S D` | العصا اليسرى |
| النظر/التصويب | تحريك العصا اليمنى | العصا اليمنى |
| الضرب | زر الضرب | زر الضرب |
| القفز / النزول من الطائرة / فتح المظلة | `مسافة` | زر القفز |
| الجري | `Shift` | زر الجري |
| الانخفاض | `C` | زر الانخفاض |
| فتح الصناديق | `F` | زر فتح الصناديق |
| التقاط الأشياء | `E` | زر الالتقاط |
| إعادة التعبئة | `R` | زر إعادة التعبئة |
| الخريطة الكاملة | `M` | زر ⛶ على الخريطة المصغّرة |

**مجرى المباراة:** تُقلع الطائرة على أحد المسارات المرسومة → تقفز في الوقت الذي تريد →
سقوط حر ثم مظلة → هبوط → افتح الصناديق واجمع الغنائم وقاتل الخصوم →
عدّاد الباقين والترتيب يتحدّثان حتى النصر 👑.

## كيف تُوزَّع الصناديق «باحتراف»؟

الخريطة تُحلَّل على بطاقة الرسوميات بثلاث تمريرات من الأعلى (إسقاط متعامد):

1. **تمريرة الارتفاعات** — شادر يكتب ارتفاع كل نقطة مُرمَّزاً بـ 16 بت، فينتج
   حقل ارتفاعات `1024×1024` يُستخدم للاصطدام والمشي والانحدار.
2. **تمريرة الماء** — تُلوَّن الخامات التي تحمل اسم ماء/بحر بالأبيض والبقية بالأسود،
   فيُستخرج قناع البحر ومستواه.
3. **تمريرة الألوان** — لقطة ملوّنة تُستخدم كصورة الخريطة المصغّرة والخريطة الكاملة.

ثم تُشتقّ: الميل، أكبر كتلة يابسة متصلة (الجزيرة)، والمسافة إلى الشاطئ (Chamfer distance).

**اختيار مواضع الصناديق** يعطي درجة لكل خليّة:

```
الدرجة = 1.25×الاستواء + 1.5×تنوّع الارتفاع حولها + 0.7×البُعد عن البحر + 0.5×كونها في العراء
```

فتُفضَّل الأرض المستوية القريبة من المباني والصخور والمعالم، وتُستبعد المنحدرات الحادة
والأماكن الملاصقة للماء والزوايا شديدة الظلمة داخل المباني. ثم يُختار المرشّحون
بطريقة جشعة مع **قيد تباعد** (نحو 26 متراً) لتغطية كل مناطق الجزيرة بالتساوي.

**الحدود** تُستخرج بتتبّع كفاف الجزيرة (Moore neighborhood) بعد تقليصها عن الشاطئ،
ثم تبسيطها بخوارزمية دوجلاس-بويكر إلى مضلّع مُرتّب. خارج المضلّع = ضرر مستمر
+ دفعة تُعيدك للداخل + جدار مرئي متوهّج.

## حجم الملف — بلا فقدان جودة

النماذج مضمّنة داخل ملف HTML واحد، لذلك يهمّ الحجم. كل التصغير المُطبَّق **بلا أي فقدان** —
لا بكسل واحد ولا رأس واحد تغيّر:

| الخطوة | الأثر |
|---|---|
| دمج البيانات المكرّرة حرفياً في GLB (`tools/optimize_glb.py`) | 45 → 27 مب |
| فهارس `uint32` → `uint16` بنفس القيم | ضمن ما سبق |
| حذف مجموعات UV لا تشير إليها أي خامة | ضمن ما سبق |
| ضغط الحمولة بـ gzip داخل الملف (يُفكّ في المتصفح) | 27 → **25 مب للملف كاملاً** |

خريطة سكتشفاب وحدها كان 52% من بياناتها تكراراً حرفياً — دمجها وحده وفّر 13 ميجابايت.

لتشغيل المُحسِّن يدوياً على نماذجك:

```bash
python3 tools/optimize_glb.py in.glb out.glb          # بلا فقدان (افتراضي)
python3 tools/optimize_glb.py --lossy in.glb out.glb  # يضيف تحويل PNG إلى JPEG
```

> فكّ الضغط يحتاج `DecompressionStream` (كروم 80+، سفاري 16.4+، فايرفوكس 113+).
> يمكنك إطفاء الضغط من مفتاح في مرحلة التصدير إن أردت متصفحاً أقدم.

## الأصوات

كل الأصوات **مُولَّدة برمجياً** بـ Web Audio (لا ملفات صوتية، لا يزيد حجم الملف):
هدير محركات الطائرة المستمر (يتغيّر مع الخانق)، رياح السقوط الحر، الطلقات، الإصابة،
القفز والهبوط والخطوات، فتح الصندوق، الالتقاط، الإسقاط، النصر والخسارة، وموسيقى القائمة.

## الحفظ والتراجع

- كل تعديل يُحفظ فوراً في `localStorage`، والنماذج والصور في `IndexedDB`.
- **إذا أغلقت الموقع وعدت، تجد نفسك في نفس المرحلة وبنفس الترتيبات.**
- `Ctrl+Z` / `Ctrl+Y` للتراجع والإعادة (حتى 80 خطوة)، وأزرار ↶ ↷ في الشريط العلوي.
- تستطيع القفز إلى أي مرحلة سابقة من تبويبات الأعلى وتعديلها ثم إعادة التصدير.
- اللعبة المُصدَّرة تحفظ تفضيلات اللاعب (الصوت، الجودة، الأصدقاء، ألوان الشخصية) في متصفحه.

## هيكل المشروع

```
src/
  main.js              نقطة الدخول: محرّر أم لعبة مُصدَّرة
  runtime.js           القائمة ← المباراة ← العودة
  style.css            كل الأنماط (RTL)
  core/
    util.js            أدوات DOM/رياضيات/حوارات/سحب
    store.js           حالة المشروع + تراجع/إعادة + حفظ تلقائي
    assets.js          مخزن الأصول (IndexedDB / حمولة مُضمّنة)
    audio.js           محرك الصوت المُولَّد برمجياً
  builder/
    app.js             الشريط العلوي والمراحل
    stage1.js          أزرار التحكم
    stage2.js          الخريطة والمسارات والصناديق والحدود
    stage3.js          القائمة الرئيسية والشخصية
    stage4.js          التجربة والتصدير
  game/
    world.js           تحميل GLB، تحليل الخريطة، الحدود، توزيع الصناديق، السماء والبحر
    character.js       الكبسولة ذات العينين + أنيميشن إجرائي + المظلة
    hud.js             واجهة اللعب والإدخال والخريطة المصغّرة
    lobby.js           القائمة واللوحات ومعاينة الشخصية
    game.js            محرّك المباراة
assets/                نماذج GLB الافتراضية
tools/build.mjs        يبني index.html الواحد
```

## حدود معروفة

- الاصطدام مبنيّ على **حقل ارتفاعات من الأعلى**، لذلك اللاعب يمشي على أسطح المباني
  ولا يدخلها، والجدران الحادة تصدّه. هذا اختيار مقصود لأنه سريع جداً ويعمل مع أي خريطة GLB.
- ملف اللعبة المُصدَّر نحو 25 ميجابايت لأن نماذج GLB مُضمّنة داخله.
  إن أردته أخفّ، استبدل الخريطة بنموذج أصغر من المرحلة 2.
- الخصوم روبوتات محلية (لا يوجد لعب شبكي حقيقي بعد).
