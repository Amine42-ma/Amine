# 👑 بطل رويال — نسخة مطوّرة

الملف الجاهز للتحميل واللعب: **`royalbattle_6.html`** — ملف واحد فقط، افتحه بأي متصفّح حديث (Chrome / Edge / Safari) على الجوال أو الحاسوب. لا يحتاج إنترنت بعد التحميل.

## ما الذي أُضيف؟

### 1) لوحة الإعداد قبل بدء اللعب
عند فتح اللعبة تظهر **لوحة الإعداد أولاً** — قبل تحميل اللعبة وقبل ظهور الواجهة. ترتّب فيها كل شيء، ثم تضغط **«▶️ ابدأ اللعبة»** فتُحمّل اللعبة وتبدأ اللعب بالترتيب الذي اخترته.

اللوحة فيها 5 تبويبات:

| التبويب | ماذا تفعل فيه |
|---|---|
| 🎮 **الأزرار** | تسحب كل زر (القفز، الضرب، الجري، العصا…) لمكانه، وتغيّر: **الحجم، الشفافية، الشكل** (دائري/مربع/سداسي/معيّن/درع)، **اللون**، و**الرمز** من أكثر من 150 إيموجي — أو **ترفع صورتك الخاصة** كأيقونة للزر. وتُظهر أو تُخفي أي زر. |
| 📊 **العدّادات** | نفس الشيء لعدّاد القتلى، الترتيب، الباقون، شريط الصحة، الخريطة المصغّرة، مؤقّت الزون، وشارة السلاح المحمول. |
| 🔫 **الأسلحة** | لكل سلاح: **رمزه ولونه**، أو صورة أيقونة ترفعها بنفسك. وزر **«استعادة ألوان الأسلحة الأصلية»**. |
| 🌳 **الأشجار والصناديق** | محرّر خريطة من الأعلى: تضيف وتسحب وتحذف **الأشجار** (صنوبر، عريضة، نخلة، شجيرة، صخرة) و**الصناديق**، مع تغيير حجم كل عنصر ودورانه + **توزيع تلقائي** حتى 400 شجرة. |
| ⚙️ **اللعب** | منع الصعود فوق الأشياء + إعدادات شارة السلاح. |

**كل الترتيب يُحفَظ في جهازك تلقائياً** ويُطبَّق في كل مرة تفتح اللعبة.
أثناء اللعب/الواجهة يوجد زر **⚙️** في الزاوية يفتح اللوحة مجدداً في أي وقت.

**أزرار مساعدة داخل اللوحة:**
- **👁️** — يخفي كل الأدوات حتى ترى الترتيب كما سيظهر فعلاً في اللعب (اضغط على أي مكان فارغ للرجوع).
- **↺** — يستعيد كل الإعدادات الافتراضية.
- المقبض السفلي — يفتح/يغلق لوحة التعديل.

---

### 2) منع الصعود فوق الأشياء نهائياً
في تبويب **⚙️ اللعب** ثلاثة أوضاع:

- **حر** — الوضع الأصلي (يصعد فوق كل شيء).
- **متوسط** — يمنع الصعود على الأشياء المتوسطة.
- **صارم** ← *الوضع الافتراضي الآن* — الصخور والصناديق والعوائق المنخفضة تصبح **جُدراناً صلبة**: لا تستطيع الصعود فوقها ولا القفز عليها إطلاقاً، ولا تخترقها.

بالإضافة إلى شريط **«ارتفاع الخطوة»** (الافتراضي الجديد `0.28` بدل `0.55`) — كلما قلّ الرقم قلّت قدرة الشخصية على تسلّق الحواف.

المباني ومداخلها تبقى قابلة للدخول، والأشجار المدمجة في الخريطة تمرّ من تحتها كالمعتاد — المنع يستهدف العوائق المنخفضة فقط.

---

### 3) وضوح السلاح المحمول
- **شارة كبيرة** أعلى الشاشة تُظهر: صورة السلاح + اسمه + نوع ذخيرته + العدّاد `المخزن / الاحتياطي` — كلها بلون السلاح نفسه. الشارة **قابلة للسحب** لأي مكان ولتغيير حجمها أو إخفائها.
- **خانات الأسلحة** أسفل الشاشة أصبحت ملوّنة بلون كل سلاح (إطار + توهّج + اسم).
- لو رفعت أيقونة خاصة لسلاح فهي تظهر في الشارة وفي الخانة بدل الصورة المولّدة.

### 4) ألوان الأسلحة
عاد لكل سلاح لونه حسب نوع ذخيرته:

| السلاح | الذخيرة | اللون |
|---|---|---|
| AK-47 / M4 | 5.56 | 🟩 أخضر |
| مسدس | 9مم | 🟨 أصفر |
| بندقية خرطوش | خرطوش | 🟥 أحمر |
| بندقية قنص | 7.62 | 🟦 أزرق |
| RPG-7 | صاروخ | 🟧 برتقالي |

ويمكنك تغيير أي لون يدوياً، أو الرجوع للأصلي بضغطة واحدة.

### 5) الأشجار كعوائق حقيقية
الأشجار التي تضعها تُبنى داخل العالم ثلاثية الأبعاد (جذع + أوراق منخفضة المضلّعات مع ظلال وتنويع لوني تلقائي)، وتُسجَّل **كعوائق صلبة** لا يمكن اختراقها ولا تسلّقها. الأشجار التي تقع في الماء أو خارج اليابسة تُحذف تلقائياً عند بناء المباراة.

## بنية المستودع

```
royalbattle_6.html   ← اللعبة الجاهزة (25.9 ميجابايت) — هذا ما تحمّله وتلعبه
royal/
  ├── setup.js       ← كود لوحة الإعداد + خطّافات اللعب (أشجار، منع تسلّق، شارة السلاح)
  ├── setup.css      ← تنسيقات اللوحة والشارة
  └── build.py       ← أداة الترقيع: تُنتج royalbattle_6.html من الملف الأصلي
```

### إعادة البناء

```bash
python3 royal/build.py royalbattle_5.html royalbattle_6.html
```

الأداة تتحقّق من أن كل مرساة ترقيع موجودة **مرّة واحدة بالضبط** داخل كود المحرّك المُصغَّر، وتتوقّف بخطأ واضح إن تغيّر المحرّك — حتى لا يُنتَج ملف نصف مُرقَّع.
