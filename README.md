# 🎬 سينمائي — CINEMAI

مولّد أفلام احترافي يعمل بالكامل **داخل متصفحك** بدون أي مفاتيح أو اشتراكات.
اكتب قصتك أو وصف المشهد، وسيحوّلها التطبيق إلى **فيلم بالصوت والصورة** مع مؤثرات بصرية وصوتية وسرد صوتي عربي.

## ✨ المميزات

- **فهم الوصف تلقائيًا:** يكتشف الجو والمشاعر من كلماتك العربية (بؤس، بحر/سمك، رعب، حرب، حب، أمل، مدينة، صحراء، فضاء، غابة) ويبني المشهد المناسب لكل جملة.
- **مؤثرات بصرية سينمائية:** مطر، فقاعات أعماق، جمر ونار، دخان، ضباب، أشعة ضوء، نجوم وسدم، حبيبات فيلم (Grain)، فينييت، اهتزاز كاميرا، حركة Ken Burns، وانتقالات ناعمة.
- **صوت مولّد بالكامل:** موسيقى تصويرية حسب الجو (حزينة، ملحمية، رومانسية…) + مؤثرات بيئية (مطر، نبض قلب، انفجارات، أعماق، رياح) + سرد صوتي عربي.
- **قصص مصوّرة (Storyboard):** لكل مشهد بطاقة مصغّرة يمكن الضغط عليها للانتقال.
- **تصدير حقيقي:** يسجّل الفيلم كملف فيديو **WebM بالصوت** لتنزيله.
- **أبعاد متعددة:** سينمائي 2.39:1 · عريض 16:9 · عمودي 9:16 (موبايل).

## ▶️ طريقة الاستخدام

1. افتح ملف **`index.html`** بالنقر المزدوج (يعمل في أي متصفح حديث — يُفضّل **Chrome** أو **Edge**).
2. اكتب قصتك في الصندوق، أو اضغط **«قصة تجريبية»**.
3. اختر النمط (أو اتركه **تلقائي**) واضبط المدة وشدة المؤثرات.
4. اضغط **🎬 توليد الفيلم** ثم **▶** للتشغيل.
5. لحفظ الفيلم: اضغط **⬇️ تصدير الفيلم** — سيُشغَّل كاملًا مرة ثم يُنزّل ملف `.webm`.

## 🔧 التقنية

مبني بالكامل بتقنيات الويب القياسية بدون أي مكتبات خارجية:
`Canvas 2D` للرسم والمؤثرات · `Web Audio API` للموسيقى والمؤثرات · `Speech Synthesis` للسرد · `MediaRecorder` للتصدير.

> ملاحظة: السرد الصوتي العربي يعتمد على الأصوات المتوفرة في نظامك/متصفحك. على ويندوز يمكن إضافة صوت عربي من إعدادات اللغة للحصول على أفضل نطق.

## 🚀 التطوير المستقبلي

التطبيق مبني بمعمارية أنماط (`THEMES`) قابلة للتوسّع. لدمج نماذج ذكاء اصطناعي احترافية لتوليد فيديو/صوت حقيقي (مثل Runway / Veo / ElevenLabs) لاحقًا، يمكن إضافة طبقة «مزوّدين» تستدعي واجهاتها البرمجية عند توفّر المفاتيح.
