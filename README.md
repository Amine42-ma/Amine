# ⚔️ ستيكمان ديويل • Stickman Duel

<div dir="rtl">

لعبة قتال **فيزيائية (Ragdoll)** ثنائية البُعد للمتصفح، مستوحاة من ألعاب Stickman الاحترافية.
شخصيات بأجساد فيزيائية حقيقية، أسلحة متعددة، ذكاء اصطناعي، وضع لاعبَين على نفس الجهاز،
خرائط متنوعة، وقوائم كاملة — كل ذلك في لعبة ويب خفيفة تعمل على الكمبيوتر والجوال بدون أي
ملفّات خارجية أو مكتبات.

</div>

A 2D **ragdoll physics** fighting game for the browser, inspired by professional
stickman duel games. Real Verlet-integrated bodies, multiple weapons, a scaling AI,
local 2-player, several arenas and a full menu system — all in a lightweight web game
that runs on desktop and mobile with **zero external assets or libraries**.

## 🎮 كيف تلعب • Controls

### 📱 اللمس (Touch / Mobile)
- **عصا التحكم** (يمين الشاشة): الحركة يمينًا/يسارًا، وادفعها لأعلى للقفز (قفزة مزدوجة في الهواء).
- **⚔️ هجوم** — ضربة بالسلاح · **⬆️ قفز** · **💨 اندفاع** · **🛡️ صد**.

### ⌨️ لوحة المفاتيح — اللاعب 1 (Player 1)
| الحركة | القفز | الهجوم | الصد | الاندفاع |
|:---:|:---:|:---:|:---:|:---:|
| `A` / `D` | `W` (×2 قفزة مزدوجة) | `J` أو `Space` | `K` | `L` |

### ⌨️ لوحة المفاتيح — اللاعب 2 (Player 2)
| الحركة | القفز | الهجوم | الصد | الاندفاع |
|:---:|:---:|:---:|:---:|:---:|
| `←` / `→` | `↑` (×2) | `Enter` | `↓` | `Shift` / `/` |

- **إيقاف مؤقت:** `Esc` أو `P` أو زر ❚❚ في الأعلى.

## ✨ المميزات • Features

- **محرك فيزياء Verlet** مكتوب من الصفر: نقاط كتلة، قيود مسافة، وقيود زاوية، مع متحكّم
  توازن نشِط يجعل الشخصية تقف وتمشي بدل أن تنهار، وكشف تصادم محصّن ضد النفق.
- **14 سلاحًا** برسم إجرائي مفصّل (تدرّجات، توهّج، أثر ضربة ملوّن): سيف، سيف عظيم، منشار
  (ضرر مستمر)، عصا، مطرقة، كرة شوكية، رمح، رمح ثلاثي، فأس، منجل، كاتانا، سيف طاقة متوهّج،
  خنجران سريعان، ومضرب مسامير.
- **7 حلبات احترافية** بخلفيات متعدّدة الطبقات (parallax) وزخارف حيّة: المعبد (بوابة/أعمدة/مشاعل)،
  الجزر الطائرة (غيوم/شمس/طيور)، كهف الحمم (حمم متوهّجة/شرر)، الدوجو (فوانيس/لافتات/جبال)،
  الأبراج الليلية (مدينة بنوافذ مضيئة/قمر/مطر)، حلبة الأبطال (جمهور)، ومحطة الفضاء (كوكب/نجوم/شبكة).
- **حركات قتالية جديدة مثل اللعبة الأصلية**:
  - **قفزة مزدوجة** (Double jump) في الهواء.
  - **اندفاع سريع** (Dash) في اتجاه الحركة.
  - **شريط طاقة/غضب** (Rage) يمتلئ بالضربات ويفعّل تلقائيًا وضعًا هجوميًا أقوى وأسرع مع هالة.
  - **صناديق قوة** تسقط في الحلبة: صحة (❤️) أو سلاح جديد (⚔️).
- **🌐 أونلاين (Online) بين الأجهزة** — لعب P2P حقيقي بلا خادم مركزي:
  - **أنشئ غرفة** → يظهر رقم، شاركه مع صديقك ليدخل به.
  - **ادخل برقم** → اكتب رقم غرفة صديقك واضغط دخول.
  - **روم عشوائي / مباراة سريعة** → ادخل ردهة مشتركة وتُطابَق مع أقرب لاعب متصل.
  > يعتمد الأونلاين على مكتبة P2P تُحمَّل عند التشغيل ويتطلّب اتصال إنترنت.
- **ذكاء اصطناعي** بأربع درجات صعوبة (سهل / عادي / صعب / جنوني): يقترب، يحفظ المسافة،
  يهاجم على دفعات، يتراجع، يصدّ، ويندفع.
- **وضع لاعبَين** محلي على نفس الجهاز، ونظام مباريات (أفضل من 1 / 3 / 5)، مؤقّت لكل جولة،
  والخروج من الحلبة (Ring-out).
- **جرافيك احترافي**: تظليل الأطراف، تعابير وجه، توهّج الأسلحة والإصابات، دم/شرر/غبار/أرقام ضرر،
  اهتزاز الكاميرا، بطء زمني عند الضربة القاضية، وتظليل حواف (vignette).
- **كاميرا ديناميكية** تكبّر وتصغّر تلقائيًا حسب المسافة بين المقاتلَين.
- **صوت مُركّب بالكامل** عبر Web Audio (مؤثرات + موسيقى) — لا ملفات صوت.
- **تحكم هاتف محسّن**: عصا تحكم + أزرار كبيرة بعناوين (هجوم/قفز/اندفاع/صد) مع اهتزاز (haptic).
- **واجهة كاملة**: قائمة، شرح، إعداد كامل، أونلاين، إيقاف مؤقت، ونتيجة — عربي (RTL) + إنجليزي، ومتجاوبة.

## ▶️ التشغيل • Running

### أسهل طريقة — ملف واحد
حمّل **`dist/stickman-duel.html`** وافتحه بأي متصفح (كل شيء بداخله: CSS + JS + الرسوم + الصوت).
مثالي للمشاركة أو اللعب دون اتصال.

### أو من المصدر (متعدد الملفات)
```bash
# افتح الملف مباشرة
xdg-open index.html

# أو خادم محلي بسيط
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

### إعادة بناء الملف الواحد
```bash
node build.js                 # ينتج dist/stickman-duel.html
```

> 💡 للصوت: انقر أي زر أولًا (المتصفحات تشترط تفاعل المستخدم لبدء الصوت).
> 🌐 للأونلاين: يلزم اتصال إنترنت (تُحمَّل مكتبة P2P عند الحاجة).

```
.
├── index.html          # الصفحة والواجهات (HUD، القوائم، الأونلاين، أزرار اللمس)

└── js/
    ├── utils.js        # الرياضيات، المتجهات، كشف تصادم القطع
    ├── physics.js      # محرك Verlet: Particle / Constraint / World
    ├── audio.js        # مؤثرات وموسيقى مُركّبة (Web Audio)
    ├── particles.js    # نظام الجسيمات (دم/شرر/غبار/أرقام)
    ├── weapons.js      # تعريفات ورسم الأسلحة (14 سلاحًا)
    ├── maps.js         # تعريفات الحلبات والأخطار (7 حلبات)
    ├── stickman.js     # المقاتل: ragdoll + تحكّم + قتال + قفز مزدوج/اندفاع/غضب + رسم
    ├── ai.js           # متحكّم الخصم الحاسوبي
    ├── input.js        # لوحة المفاتيح + عصا التحكم واللمس + اهتزاز
    ├── network.js      # الأونلاين P2P (Trystero): غرف + مباراة سريعة
    └── game.js         # آلة الحالات، الكاميرا، الجولات، الصناديق، الحلقة الرئيسية
```

## 🛠️ ملاحظات تقنية • Technical notes

- **بلا اعتماديات (Zero dependencies):** لا مكتبات، لا CDN، لا صور — كل الرسم إجرائي على Canvas.
- **حلقة بخطوة ثابتة (Fixed timestep)** للفيزياء عند 60Hz مع رسم متغيّر، للاستقرار.
- كشف التصادم مُحصّن ضد الاختراق العميق والنفق عبر المنصّات الرقيقة (فحص هبوط ممسوح +
  دفع من أقرب وجه + تقييد السرعة).
