# ⚔️ ستيكمان ديويل • Stickman Duel

<div dir="rtl">

لعبة قتال **فيزيائية (Ragdoll)** ثنائية البُعد للمتصفح، مستوحاة من ألعاب Stickman الاحترافية.
شخصيات بأجساد فيزيائية حقيقية، أسلحة متعددة، ذكاء اصطناعي، وضع لاعبَين على نفس الجهاز،
خرائط متنوعة، وقوائم كاملة — كل ذلك في لعبة ويب خفيفة تعمل على الكمبيوتر والجوال بدون أي
ملفّات خارجية أو مكتبات.

</div>

A 2D **ragdoll physics** fighting game for the browser, inspired by professional
stickman duel games. Real Verlet-integrated bodies, multiple weapons, a scaling AI,
local 2-player, several arenas and a full menu system — all in a lightweight web game
that runs on desktop and mobile with **zero external assets or libraries**.

## 🎮 كيف تلعب • Controls

### 📱 اللمس (Touch / Mobile)
- **عصا التحكم** (يمين الشاشة): الحركة يمينًا/يسارًا، وادفعها لأعلى للقفز.
- **⚔️ زر الهجوم** — ضربة بالسلاح.
- **⬆️ زر القفز**.
- **🛡️ زر الصد** — يقلّل الضرر والدفع.

### ⌨️ لوحة المفاتيح — اللاعب 1 (Player 1)
| الحركة | القفز | الهجوم | الصد |
|:---:|:---:|:---:|:---:|
| `A` / `D` | `W` | `J` أو `Space` | `K` |

### ⌨️ لوحة المفاتيح — اللاعب 2 (Player 2)
| الحركة | القفز | الهجوم | الصد |
|:---:|:---:|:---:|:---:|
| `←` / `→` | `↑` | `Enter` | `↓` |

- **إيقاف مؤقت:** `Esc` أو `P` أو زر ❚❚ في الأعلى.

## ✨ المميزات • Features

- **محرك فيزياء Verlet** مكتوب من الصفر: نقاط كتلة، قيود مسافة، وقيود زاوية، مع متحكّم
  توازن نشِط يجعل الشخصية تقف وتمشي بدل أن تنهار.
- **8 أسلحة** لكل منها مدى وضرر ووزن وأسلوب تأرجح مختلف: سيف، منشار (ضرر مستمر)، عصا،
  مطرقة، رمح، فأس، كاتانا، وخنجران سريعان.
- **5 حلبات** بتصاميم وأخطار مختلفة: المعبد، الجزر الطائرة، كهف الحمم (ضرر)، الدوجو، والأبراج.
- **ذكاء اصطناعي** بأربع درجات صعوبة (سهل / عادي / صعب / جنوني): يقترب، يحفظ المسافة،
  يهاجم على دفعات، يتراجع ويصدّ.
- **وضع لاعبَين** محلي على نفس الجهاز.
- **نظام مباريات**: أفضل من 1 / 3 / 5 جولات، مؤقّت لكل جولة، وحسم بالصحة عند انتهاء الوقت.
- **الخروج من الحلبة (Ring-out)** والسقوط في الفراغ أو الحمم.
- **تأثيرات بصرية**: دم، شرر، غبار، أرقام ضرر، اهتزاز الكاميرا، بطء زمني عند الضربة القاضية.
- **كاميرا ديناميكية** تكبّر وتصغّر تلقائيًا حسب المسافة بين المقاتلَين.
- **صوت مُركّب بالكامل** عبر Web Audio (مؤثرات + موسيقى خلفية) — لا ملفات صوت.
- **واجهة كاملة**: قائمة رئيسية، شرح، اختيار الأسلحة والألوان والحلبة والصعوبة، إيقاف مؤقت،
  وشاشة نتيجة — بدعم كامل للعربية (RTL) والإنجليزية، ومتجاوبة مع الجوال.

## ▶️ التشغيل • Running

اللعبة ثابتة بالكامل (HTML/CSS/JS فقط). افتح `index.html` مباشرة في المتصفح، أو قدّمها عبر
أي خادم ثابت:

```bash
# خيار 1: افتح الملف مباشرة
xdg-open index.html      # أو انقر عليه نقرًا مزدوجًا

# خيار 2: خادم محلي بسيط
python3 -m http.server 8000
#  ثم افتح http://localhost:8000
```

> 💡 للحصول على الصوت، انقر أي زر أولًا (متصفحات الويب تشترط تفاعل المستخدم لبدء الصوت).

## 🛠️ ملاحظات تقنية • Technical notes

- **بلا اعتماديات (Zero dependencies):** لا مكتبات، لا CDN، لا صور — كل الرسم إجرائي على Canvas.
- **حلقة بخطوة ثابتة (Fixed timestep)** للفيزياء عند 60Hz مع رسم متغيّر، للاستقرار.
- كشف التصادم مُحصّن ضد الاختراق العميق والنفق عبر المنصّات الرقيقة (فحص هبوط ممسوح +
  دفع من أقرب وجه + تقييد السرعة).
