# 🎬 استوديو الأفلام الذكي — AI Film Studio

حوّل **وصفًا أو قصة** إلى **فيلمٍ سينمائيّ** كامل: صورة متحرّكة، تعليق صوتي/ترجمة،
موسيقى ومؤثرات، ومعالجة لونية تعكس **الإحساس** الذي تريده (بؤس، توتر، دهشة،
ملحمة، رومانسية…). يكفي أن تكتب ما تريد — ويفهمه الاستوديو ويُنتجه.

> **بصراحة تقنية:** لا يوجد تطبيق يُدرّب من الصفر نموذجًا يولّد أفلام 4K واقعية —
> تلك نماذج ضخمة (Sora, Veo, Runway…) تُستخدَم عبر مفاتيح API. هذا المشروع هو
> **الاستوديو المتكامل** الذي يربط كل المراحل ويُخرج فيلمًا حقيقيًا: يعمل **بالكامل
> بلا أي مفاتيح** عبر محرّك سينمائيّ داخليّ (تدرّجات مزاجية، حركة كاميرا افتراضية،
> حبيبات فيلم، ترجمة عربية، موسيقى مركّبة)، **ويرتقي تلقائيًا** إلى فيديو ذكاء
> اصطناعيّ واقعيّ وصوتٍ منطوق بمجرد إضافة مفاتيح المزوّدين.

---

## ✨ كيف يعمل (خط الإنتاج)

```
الوصف / القصة
     │
     ▼
1) العقل الإخراجي  ──►  سيناريو إنتاجي كامل (JSON)
   (Claude أو الكاتب الداخلي)     مشاهد · لقطات · زوايا · إضاءة · مزاج · تعليق · موسيقى · مؤثرات
     │
     ▼
2) توليد الوسائط (مزوّدون قابلون للتوصيل)
   • فيديو : المحرّك السينمائي الداخلي  ▸ أو fal.ai / Replicate
   • صوت   : ترجمة نصية مدمجة          ▸ أو ElevenLabs / OpenAI
   • موسيقى: تأليف مركّب حسب المزاج
     │
     ▼
3) المونتاج والمعالجة (ffmpeg)
   دمج اللقطات · مزج الصوت · حرق الترجمة العربية · تدرّج لوني · انتقالات
     │
     ▼
   🎞 فيلم MP4 نهائي
```

كل مزاج له **لغته اللونية والموسيقية**: أزرقٌ باردٌ للبؤس، برتقاليّ مهيبٌ للملحمة،
أزرقٌ عميقٌ للدهشة، ورديٌّ للرومانسية… فتشعر بالقصّة لا أن تراها فقط.

## 🚀 التشغيل

```bash
npm install          # التبعيات (تتضمّن ffmpeg جاهزًا عبر ffmpeg-static)
npm run setup        # يتحقّق من الخطوط العربية (مضمّنة أصلًا)
npm start            # ثم افتح http://localhost:8787
```

المتطلّب الوحيد: **Node.js ≥ 20**. لا حاجة لتثبيت ffmpeg يدويًا، ولا لأي مفاتيح
للبدء.

### الترقية إلى واقعية أعلى (اختياري)

انسخ `.env.example` إلى `.env` واملأ ما لديك، ثم:

```bash
node --env-file=.env server.js
```

| تريد… | أضِف |
|------|------|
| سيناريو أذكى يفهم قصّتك بدقّة | `ANTHROPIC_API_KEY` |
| فيديو واقعيّ من النص | `FAL_KEY` (أو `REPLICATE_API_TOKEN` + `REPLICATE_VIDEO_MODEL`) |
| تعليق صوتيّ منطوق | `ELEVENLABS_API_KEY` أو `OPENAI_API_KEY` |

الاستوديو يكتشف المفاتيح تلقائيًا ويستخدمها؛ وإذا فشل أي مزوّد يعود للمحرّك الداخلي
بسلاسة دون توقف الإنتاج.

## 🎛 خيارات الإنتاج (من الواجهة)

- **الوصف/القصة** — نصّك الحرّ؛ صِف الإحساس والتفاصيل بدقّة.
- **نمط الفيلم**:
  - **سينمائي (أجواء)** — حقول لونية متحرّكة حسب المزاج، حركة كاميرا، حبيبات فيلم.
  - **رسوم Stickman متحرّكة** — شخصيات مرسومة تمشي وتركض وتتقاتل وتسقط وتقفز
    وترقص وتحتفل، بمشاهد مدينة/جبال/تلال/نجوم. **مولّدة برمجيًا بالكامل بلا أي
    مفاتيح** — مثاليّة لتوليد **أفلام طويلة من وصفٍ صغير**. يفهم المخرج أفعال قصّتك
    (يمشي/يقاتل/يسقط/يحتفل… بالعربية والإنجليزية) ويحوّلها إلى حركة.
- **المزاج** — تلقائي (يُستنتَج من الكلمات) أو اختيار يدوي.
- **اللغة** — عربية / إنجليزية / تلقائي.
- **نسبة الإطار** — 16:9 سينمائي · 9:16 عمودي · 2.39:1 عريض.
- **المدة** — 15 إلى 150 ثانية.
- **الجودة** — مسودة 720p · عالية 1080p · فائقة 4K.

## 🧱 البنية

```
server.js                 خادم Express + SSE + بثّ الفيديو
src/
  config.js               الإعداد واكتشاف المزوّدين
  pipeline/
    jobs.js               سجلّ المهامّ + بثّ التقدّم الحيّ
    orchestrator.js       تشغيل خطّ الإنتاج كاملًا
  screenplay/
    prompt.js             موجّه Claude لبناء السيناريو
    generate.js           Claude + الكاتب الداخلي + التطبيع
  providers/
    video.js              سينمائي داخلي · fal · replicate
    voice.js              ترجمة · elevenlabs · openai
    music.js              تأليف موسيقيّ مركّب
  render/
    cinematic.js          إخراج اللقطة الواحدة (كاميرا/مزاج/حبيبات)
    raster.js             محرّك رسم ثنائي الأبعاد نقيّ (بلا تبعيات)
    subtitles.js          توليد ملفّات ASS العربية
    assemble.js           المونتاج والمزج والمعالجة النهائية
    ffmpeg.js             غلاف ffmpeg
  stickman/
    figure.js             الهيكل العظمي ومكتبة الحركات (مشي/ركض/قتال/سقوط…)
    scene.js              خلفيات المشاهد ورسم الشخصيات
    director.js           مخرج الأفعال (نصّ القصة → حركة)
    render.js             توليد الإطارات وبثّها إلى ffmpeg
  util/                   الألوان/المزاج، الملفّات، السجلّ
public/                   واجهة الاستوديو (RTL)
assets/fonts/             خطوط عربية (Amiri/Cairo) لحرق الترجمة
```

## 🔌 واجهة برمجية مختصرة

| المسار | الوصف |
|--------|-------|
| `GET /api/capabilities` | المزوّدون المتاحون وخيارات الإنتاج |
| `POST /api/jobs` | إنشاء فيلم `{ brief, mood, language, aspect, duration, quality }` |
| `GET /api/jobs/:id/events` | تقدّم حيّ (SSE) |
| `GET /api/jobs/:id/plan` | السيناريو الإنتاجي (JSON) |
| `GET /api/jobs/:id/film` | بثّ/تحميل الفيلم (`?download=1`) |

## 📝 ملاحظات

- الملفّات المُنتَجة تُحفَظ في `storage/<jobId>/` (غير متتبَّعة في git).
- المحرّك الداخلي يُنتج أفلامًا **تجريديّة أجواء سينمائية** (حقول لونية متحرّكة
  بترجمة وموسيقى) — أسلوب مقصود وصادق بلا مفاتيح؛ للحصول على مَشاهد واقعية
  بأشخاص وأماكن، فعِّل مزوّد فيديو.
- مبنيّ على `ffmpeg-static` فلا يحتاج تثبيت ffmpeg على النظام.
